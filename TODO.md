# Update Checker Bottom Sheet - Roadmap

This document outlines planned features and improvements for future versions of the package.

## 🚀 High Priority
- [ ] **Localization Support**: Add built-in support for common languages (ES, FR, DE, HI, etc.) without requiring manual string overrides.
- [ ] **In-App Progress Notifications**: Option to show download progress in the system notification tray.
- [ ] **Custom API Support**: Allow fetching version info from custom JSON endpoints (non-GitHub).

## ✨ UI/UX Improvements
- [ ] **Glassmorphism Theme**: Add a pre-built glassmorphic theme option for a more modern look.
- [ ] **Animations**: Add subtle entry animations for the release notes pill and icons.
- [ ] **Adaptive Layout**: Better handling for tablets and landscape mode.

## 🛠️ Technical Refinements
- [ ] **Unit Tests**: Implement comprehensive unit tests for `UpdateUtils` (version comparison) and `UpdateLogic`.
- [ ] **Platform Expansion**: Explore support for other platforms (iOS, Windows, Linux) if suitable OTA engines become available.
- [ ] **Error Handling**: More granular error reporting for specific HTTP failures (e.g., Rate Limiting).

## 📖 Documentation
- [ ] **Example App Gallery**: Add more presets to the example app to showcase different design possibilities.
- [ ] **Video Tutorial**: Create a short GIF/Video demonstrating the update flow for the README.
